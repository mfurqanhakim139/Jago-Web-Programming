# Jago Web Programming - Kode Bab 1 s.d. Bab 6 (Generator)

## Cara Pakai
Jalankan:
python generate_jago_web_programming_kode_bab1-6.py

Akan dibuat folder `jago-web-programming-kode-bab1-6/` berisi file HTML/CSS yang bisa langsung dibuka di browser.

## Catatan penting
- Repo GitHub yang Anda kirim saat ini hanya berisi 2 file HTML (bukan struktur Bab 1–6).
- Bab 6 pada dokumen buku yang terambil hanya berupa outline, jadi file Bab 6 di sini adalah implementasi runnable sesuai outline.
