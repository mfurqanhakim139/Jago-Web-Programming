# BAB 7 – Backend PHP & Database MySQL (Minggu 7)

Catatan: Pada dokumen buku yang terbaca, Bab 7 hanya menampilkan outline materi (tanpa listing kode lengkap). Outline Bab 7 mencakup:
- PHP Native dasar (echo, variabel, komentar, if-else, foreach)
- Menangkap data form: $_POST & $_GET
- Database MySQL (phpMyAdmin) + membuat tabel
- Koneksi & CRUD 1 (Create & Read) dengan koneksi.php

Di folder ini saya sediakan proyek contoh **runnable** yang sesuai dengan outline tersebut.
Jalankan lewat XAMPP/Laragon (letakkan folder proyek di `htdocs` / `www`).

## Cara jalan cepat
1) Buat database & tabel: import file `database.sql` via phpMyAdmin.
2) Edit `koneksi.php` (host, user, pass, dbname).
3) Buka `index.php` di browser: http://localhost/nama-folder/bab7/index.php
